# AGENTS.md

## Что это за приложение

Симулятор политик доступа — учебный проект Хекслета по курсу AI SDLC. Приложение на React, Mantine, Vite и TypeScript позволяет выдавать и отзывать разрешения пользователям и группам, проверять доступ к сервисам и импортировать/экспортировать конфигурацию. Серверной части нет: конфигурация хранится только в браузере пользователя.

## Каталоги

- `src/domain` — модель данных (`model.ts`) и единственный расчёт доступа (`access.ts`). Чистые функции без браузера и без чтения часов: момент расчёта приходит параметром `at`.
- `src/app` — слой приложения: хранилище браузера, формат файла конфигурации, операции с разрешениями, учебные данные и хук `useSimulator`, который отдаёт компонентам всё нужное.
- `src/components` — экраны на React и Mantine: `App`, `PermissionsPanel`, `ConfigTransfer`. Не читают `localStorage` и не импортируют `src/domain`, а работают только через `src/app`.

## Команды проверок

Запускать из корня репозитория:

```bash
make setup      # npm ci и сборка
make test       # vitest
make lint       # oxlint и oxfmt --check
make lint-arch  # ast-grep по src, правила из rules/
make build      # tsc --noEmit и vite build
```

## TDD

Реализацию ведёт скилл tdd, зови его при новой логике и при исправлении.

При первом взятии изменения в реализацию скилл остановится и спросит, на каких границах модуля писать тесты. Это ожидаемое поведение: на вопрос нужно ответить до начала работы.
